# EmptyMicroRobot

> یک هسته تصمیم‌گیری کوچک، خودکفا و «از هر چیزی یاد می‌گیرد» برای ربات‌ها و برنامه‌های طولانی‌مدت پایتون.

[![Python 3.8+](https://img.shields.io/badge/python-3.8%2B-blue.svg)](https://www.python.org/downloads/)
[![License](https://img.shields.io/badge/license-MIT-green.svg)](LICENSE)
[![Dependencies](https://img.shields.io/badge/dependencies-numpy%20only-orange.svg)](https://numpy.org/)

**EmptyMicroRobot** یک ماژول حافظه تطبیقی تک‌فایلی است که به هر ربات (یا هر برنامه پایتونی) یک تکه کوچک هوش تصمیم‌گیری می‌دهد. آن را در حلقه کنترل خود قرار دهید، آنچه می‌دانید به آن بیاموزید و بگذارید از تجربه یاد بگیرد — بدون GPU، بدون رمزگذار پیش‌آموزش‌دیده، بدون مرحله برازش آفلاین.

## چرا EmptyMicroRobot؟

بیشتر سیستم‌های تطبیقی فرض می‌کنند که شما یک GPU، یک مجموعه داده بزرگ و هفته‌ها زمان برای آموزش دارید. EmptyMicroRobot خلاف این را فرض می‌کند. این ماژول برای لبه (edge) طراحی شده است — کنترل‌کننده‌های ربات، سیستم‌های نهفته (embedded) و هر برنامه‌ای که نیاز به تطبیق در زمان واقعی بدون رشد نامحدود حافظه دارد.

این ماژول یک **حافظه تصمیم‌گیری کراندار و خودمقیاس‌شونده** را پیاده‌سازی می‌کند که:

- **واقعاً هر چیزی** را به عنوان ورودی می‌پذیرد — متن، اعداد، دیکشنری‌ها، آرایه‌های NumPy، DataFrame‌های pandas، بایت‌ها، ترکیب‌های تودرتو یا اشیاء دلخواه.
- از **هش کردن ویژگی** استفاده می‌کند، بنابراین هیچ مرحله برازش واژگان وجود ندارد و حافظه صرف‌نظر از حجم داده‌ای که می‌بیند، محدود می‌ماند.
- از **نتایج** یاد می‌گیرد، نه فقط برچسب‌ها — هر رویداد یک برچسب زمانی، تعداد استفاده و امتیاز شگفتی (surprise) دارد.
- هوشمندانه فراموش می‌کند از طریق **افت زمانی**، بنابراین اعتقادات قدیمی محو می‌شوند در حالی که رویدادهای جدیدتر بیشتر حفظ می‌شوند.

## ویژگی‌ها

| ویژگی | توضیح |
|---|---|
| **توکن‌سازی جهانی** | متن، اعداد، دیکشنری‌ها، آرایه‌ها، DataFrame‌ها، بایت‌ها، ساختارهای تودرتو، اشیاء دلخواه |
| **هش کردن ویژگی** | O(#توکن) در هر فراخوانی، بدون برازش واژگان، حافظه کراندار |
| **یادگیری رویدادی** | `learn()` برای آموزش نظارتی؛ `learn_episode()` برای حالت → عمل → نتیجه |
| **فراموشی تطبیقی** | افت نیمه‌عمر با حفظ وزن‌دهی شده بر اساس شگفتی |
| **پیشنهاد نامزد کراندار** | `decide(state)` اقدامات را از حافظه + قواعد + بودجه کاوش تولید می‌کند |
| **مدل جهانی تجربی** | جدول `(state_sketch, action) → reward` با تعداد/میانگین/واریانس |
| **محدودیت‌های ایمنی سخت** | فراخوانی `constrain()` به عنوان وتو عمل می‌کند، در صورت خطا بسته می‌شود (fails closed) |
| **قابلیت توضیح** | `msg.explain()` تجزیه‌های قابل خواندن برای انسان و عددی را برمی‌گرداند |
| **کالیبراسیون** | جدول قابلیت اطمینان (سطل اطمینان → نرخ موفقیت مشاهده‌شده) برای ECE/Brier قابل اندازه‌گیری |
| **پایداری** | `save()` / `load()` با فشرده‌سازی اختیاری `joblib` |
| **ایمنی رشته‌ای** | تمام متدهای عمومی تغییردهنده توسط یک `RLock` محافظت می‌شوند |

## نصب

EmptyMicroRobot فقط به **NumPy** نیاز دارد. هر چیز دیگری اختیاری است و در صورت عدم دسترسی، به‌طور خودکار به مسیرهای کد معادل فقط NumPy بازمی‌گردد.

```bash
pip install numpy
```

وابستگی‌های اختیاری (در صورت قابل وارد کردن استفاده می‌شوند):

```bash
pip install scikit-learn joblib pandas
```

- **scikit-learn** — MiniBatchKMeans برای خوشه‌بندی موضوعی، FeatureHasher
- **joblib** — فایل‌های ذخیره فشرده
- **pandas** — توکن‌سازی بومی Series/DataFrame

> **توجه:** بارگذاری فایلی که با یک بک‌اند متفاوت ذخیره شده است (مثلاً ذخیره با `joblib` اما بارگذاری بدون آن) یک هشدار صادر می‌کند، زیرا دو هشر بیت‌سازگار نیستند.

## شروع سریع

```python
from empty import EmptyRobot

robot = EmptyRobot()

# آموزش نظارتی — حقیقت زمینی را به آن می‌دهید
robot.learn("turn on the lights", "lights_on")
robot.learn("turn off the lights", "lights_off")
robot.learn({"sensor": "bumper", "value": 1}, "stop_and_backup")

# درخواست پاسخ
msg = robot.response("please turn the lights on")
print(msg.content, msg.confidence)
# -> "lights_on" 0.83

print(msg.ranking)
# -> [("lights_on", 0.9), ("lights_off", 0.1)]

# به حدس خود ربات پاداش یا تنبیه بدهید
if msg.content == "lights_on":
    msg.reward()   # "بله، درست است" — بیشتر به آن اعتماد کن
else:
    msg.punish()   # "نه، اشتباه است" — کمتر به آن اعتماد کن

# تصمیم‌گیری بین مجموعه‌ای از گزینه‌های ثابت
decision = robot.decide(
    {"battery": 0.12, "enemy": True},
    options=["attack", "defend", "retreat"]
)
print(decision.content, decision.ranking)

# بگذارید از تجربه حرکت پیشنهاد دهد
free = robot.decide({"battery": 0.12})  # استخر نامزد کراندار

# یادگیری یک رویداد: حالت -> عمل -> نتیجه
robot.learn_episode(
    {"battery": 0.12}, "dock",
    outcome="docked", reward=1.0
)

# مشاهده بدون آموزش
robot.observe({"battery": 0.11})

# محدودیت ایمنی
robot.constrain(lambda state, action: action != "dart" or state["armed"])

# شبیه‌سازی: انتظار دارید چه اتفاقی بیفتد؟
print(robot.simulate({"battery": 0.11}, "dock"))

# توضیح: چرا آن پاسخ؟
print(robot.explain(msg))

# ذخیره و بارگذاری
robot.save("robot_state.joblib")
robot2 = EmptyRobot().load("robot_state.joblib")
```

## مفاهیم اصلی

### حلقه

```
حالت --> [ رمزگذار ] --> زمینه کاری
            |
            +------------+------------+
            ردپای      خلاصه‌های    قواعد
            رویدادی     معنایی       رویه‌ای
            +------ تولیدکننده نامزد (استخر کراندار) ----+
                    فیلتر ایمنی (ردهای سخت)
                    ارزیاب (اصطلاحات نرمال‌شده)
                    تصمیم --> عمل --> نتیجه
                    انتساب خطا + به‌روزرسانی‌های کوچک
```

### چهار ستون

1. **رویدادهایی با نتایج.** `learn_episode(state, action, outcome, reward)` آنچه را *پس از عمل اتفاق افتاده* ثبت می‌کند، نه فقط آنچه گفته شده. هر ردپا دارای برچسب زمانی، تعداد استفاده و امتیاز شگفتی است.

2. **فراموشی که مجازات نیست.** وزن‌ها با نیمه‌عمر (بر حسب رویداد، یا به‌صورت اختیاری بر حسب زمان واقعی) افت می‌کنند، و ردپاهای با شگفتی بالا کندتر افت می‌کنند — بنابراین یک جهان در حال تغییر دیگر با یک اعتقاد سه‌ساله پاسخ داده نمی‌شود.

3. **پیشنهاد جدا از ارزیابی.** `decide(state)` بدون `options` یک استخر نامزد *کراندار* از نزدیک‌ترین ردپاها، قواعد تقطیرشده و اقدامات کم‌آزمایش‌شده می‌سازد. نمی‌تواند یک قابلیت جدید توهم کند، اما می‌تواند در موقعیتی که هیچ‌کس شمارش نکرده عمل کند.

4. **مدل جهانی به‌اندازه‌ای کوچک که صادق باشد.** یک جدول تجربی با کلید `(state_sketch, action)` که تعداد، میانگین و واریانس پاداش مشاهده‌شده را ذخیره می‌کند. ارزیاب هرگز اعدادی با واحدهای متفاوت را جمع نمی‌کند — هر اصطلاح قبل از وزن‌دهی در مجموعه نامزد فعلی رتبه‌بندی و نرمال می‌شود.

## مرجع API

### ساخت

```python
EmptyRobot(
    memory_size=20000,
    components={...},   # روشن/خاموش کردن اجزای جداگانه
    tuning={...},       # بازنویسی پیش‌فرض‌ها؛ None یعنی خودمقیاس‌شونده
)
```

### آموزش

| متد | توضیح |
|---|---|
| `learn(a, b)` | آموزش نظارتی؛ برای زنجیره‌سازی `self` را برمی‌گرداند |
| `learn_episode(state, action, outcome, reward)` | ثبت یک رویداد کامل حالت-عمل-نتیجه |
| `observe(state)` | به‌روزرسانی زمینه کاری بدون آموزش |

### عمل

| متد | توضیح |
|---|---|
| `response(text)` | دریافت پاسخ با اطمینان و رتبه‌بندی |
| `decide(state, options=None)` | انتخاب بین گزینه‌های ثابت یا استخر نامزد تولیدشده |
| `simulate(state, action)` | پیش‌بینی نتیجه مورد انتظار |
| `explain(msg)` | توضیح قابل خواندن برای انسان درباره یک تصمیم |

### بازخورد

| متد | توضیح |
|---|---|
| `msg.reward()` | علامت‌گذاری یک حدس درست |
| `msg.punish()` | علامت‌گذاری یک حدس نادرست |

### ایمنی و پایداری

| متد | توضیح |
|---|---|
| `constrain(callback)` | افزودن یک فراخوانی وتوی سخت؛ در صورت خطا بسته می‌شود |
| `save(path)` / `load(path)` | ذخیره و بازیابی حالت |
| `stats()` | عکس فوری از آمار داخلی |

## معماری

```
┌─────────────────────────────────────────────────────────┐
│                     EmptyRobot                          │
├─────────────┬─────────────┬─────────────┬───────────────┤
│  رمزگذار    │  حافظه      │  تصمیم      │  مدل جهانی    │
│             │             │             │               │
│ توکن‌ساز    │ ردپای       │ تولیدکننده  │ (state_sketch │
│ جهانی       │ رویدادی     │ نامزد       │  action) →    │
│    ↓        │    +        │    +        │  جدول پاداش   │
│ هش وزن‌دار  │ خلاصه‌های   │ فیلتر       │               │
│ با IDF      │ معنایی      │ ایمنی       │               │
│ بردار       │    +        │    +        │               │
│             │ قواعد      │ ارزیاب      │               │
│             │ رویه‌ای     │ (نرمال‌شده) │               │
└─────────────┴─────────────┴─────────────┴───────────────┘
```

### کلیدهای اجزا

همه اجزا می‌توانند به‌صورت جداگانه از طریق `components={...}` غیرفعال شوند:

```python
robot = EmptyRobot(components={
    "world_model": False,   # غیرفعال کردن جدول پاداش تجربی
    "merge": True,          # فعال کردن ادغام ردپاهای تقریباً تکراری
    "lsh": True,            # فعال کردن پیش‌فیلتر سطلی
})
```

### امتیازدهی

امتیاز ارزیاب یک مجموع وزن‌دار از اصطلاحات رتبه‌بندی و نرمال‌شده است:

```
score = wE·z(تجربه) + wP·z(پیش‌بینی‌شده)
      + wV·z(ارزش) - wR·z(ریسک) - wU·z(عدم قطعیت)
```

هر اصطلاح از طریق `msg.explain()` قابل بررسی است.

## کارایی

اندازه‌گیری‌شده در ۲۰٬۰۰۰ حافظه روی سخت‌افزار استاندارد:

| عملیات | p50 | p95 |
|---|---|---|
| `response()` | ۱٫۳۹ میلی‌ثانیه | ۱٫۵۶ میلی‌ثانیه |
| `learn()` | ۰٫۹۴ میلی‌ثانیه/فراخوانی | — |
| `decide()` (استخر تولیدشده) | ۱٫۴۳ میلی‌ثانیه/فراخوانی | — |

- **هش کردن ویژگی** O(#توکن) در هر فراخوانی است — هیچ مرحله برازش واژگان وجود ندارد.
- **حافظه کراندار است** (پیش‌فرض ۲۰٬۰۰۰) و در صورت پر شدن، کم‌اعتمادترین ورودی را حذف می‌کند و حافظه و تأخیر را به‌طور نامحدود محدود نگه می‌دارد.
- **شاخص شباهت افزودنی است** — یک `learn()` ردیف جدید را در یک بلوک در انتظار قرار می‌دهد به‌جای بازسازی.
- **هیچ ماتریس وزن متراکمی وجود ندارد** — تنها آرایه‌های متراکم، مراکز موضوعی و یک طرح‌واره صفحه تصادفی کوچک هستند، که همین امر استقرار نهفته را امکان‌پذیر می‌کند.

## چه چیزی نیست

EmptyMicroRobot عمداً درباره دامنه خود صادق است. این **نیست**:

- **یک مدل زبانی.** همپوشانی توکن را از طریق یک هش تطبیق می‌دهد. دو بازنویسی بدون توکن مشترک برای آن غریبه هستند.
- **کالیبره‌شده به‌طور ساختاری.** `msg.confidence` یک ترکیب اکتشافی مستند است؛ `msg.calibrated_confidence` قبل از معنادار بودن به داده نیاز دارد.
- **حل‌کننده ناشناخته‌های ناشناخته.** نویی خطر اشتها را کاهش می‌دهد، اما این همان دانستن خطرناک بودن نیست.
- **یک برنامه‌ریز.** مدل جهانی یک جدول تجربی یک‌مرحله‌ای است، نه یک شبیه‌ساز. هیچ جست‌وجویی روی آینده‌ها وجود ندارد.
- **یک مورد ایمنی.** `constrain()` یک وتوی سخت است، نه جایگزینی برای یک کنترل‌کننده محدود. فراخوان همچنان مالک سخت‌افزار است.
- **یک الگوریتم انتساب اعتبار.** انتساب خطای `stats()` تلمتری به‌علاوه حداکثر دو تلنگر کوچک است.

> **اعداد اطمینان احتمال درستی نیستند** مگر اینکه جدول قابلیت اطمینان روی توزیع *شما* اندازه‌گیری شده باشد.

## مشارکت

مشارکت‌ها welcomed هستند. اگر جزئی را اضافه می‌کنید، لطفاً:

1. یک پرچم به `_DEFAULT_COMPONENTS` اضافه کنید تا قابل حذف (ablate) باشد.
2. یک ورودی متناظر به `_DEFAULT_TUNING` برای هر ابرپارامتر اضافه کنید.
3. یک اندازه‌گیری را وارد کنید — اجزایی که خوب به نظر می‌رسند اما پاداش را در حلقه بسته کاهش می‌دهند **غیرفعال** ارسال می‌شوند (به `merge` به عنوان مثال نگاه کنید).
